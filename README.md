# 拾光 · AI 工具宇宙

单文件静态页面：HTML、CSS、JavaScript 均在 `index.html`。Three.js r180 从本站 `vendor/three/build/` 加载（importmap 指向本地，页面无任何外部网络依赖），工具数据从 `data/tools.json` 加载。不需要框架或构建步骤。

## 本地运行

在项目根目录启动静态 HTTP 服务：

```powershell
cd <项目根目录>
python -m http.server 8000
```

打开 `http://localhost:8000`。页面完全离线可用（Three.js 走本站 `vendor/`），但必须通过 HTTP 打开才能用 ES 模块和读取 JSON；直接双击 HTML 无法读取数据。

## 交互与数据

- 首页中间显示「让好工具，离你更近。」；底部九个分类按钮始终保留空分类和数量。

  （左 30% 磨砂列表面板 / 右 70% 独立黑洞视口）。
- 分类页左侧滚轮只滚动列表，不缩放背景星系；右侧可拖拽旋转黑洞周围的星空与盘面倾角。
- 手机（≤850px）退化为单列列表，右侧黑洞视口隐藏。
- 列表使用 `name`、`url`、`category`、`tags`、`summary`、`score` 字段，并按 `score` 降序排列。安全的 HTTP(S) 名称链接在新窗口打开，列表项有 hover 效果。

- 页面优先使用现有真实工具数据。当前 361 条数据有 359 条归入九类，另 2 条待归类，不会显示成额外类别。
- 若 JSON 加载失败或数据格式无效，页面显示 3 条演示数据和说明，并可选择继续查看可交互的演示页或重新加载；这不是生产数据源。

## 首页星系（纯粒子，零贴图）

首页星系**没有任何贴图**：没有星云图、没有 CanvasTexture、没有渐变平面。
背景是 `renderer.clearColor` 的纯黑 `#000`，整个天体由 82450 颗粒子构成，**2 次绘制**。

- **四组粒子**
  - 宇宙星场 7050 颗（`aLayer=0`，按 `aPar` 吃视差）
  - 核球 3400 颗：白色内核（30%，r<0.20 世界≈12.5px）+ 金色外晕（70%，铺到 2.0 世界≈125px）
  - 旋臂星尘 72000 颗：单颗投影**平均 1.35px / 最大 2.38px**
  - 星际尘埃带 3600 颗：单独一个 Points，用**乘法混合**做遮挡
- **粒子尺寸反推**：`gl_PointSize = aSize × uScale / dist`。uScale = `h/(2·tan(fov/2))`，
  本机 `uScale≈1159`、dist 17.5，所以 aSize 0.012~0.036 → 0.8~2.4px。
  下限必须 `clamp(..., uPixelRatio*1.0, ...)`，否则亚像素会让整层闪烁。
- **材质**：纯高斯 `a = exp(-d2*11) × (1 - smoothstep(0.12,0.25,d2))`。
  旧版 `exp(-d2*42)` 的中心是硬核，缩到 1px 就成了方形色块。
- **混合**：发光粒子 `AdditiveBlending`；尘埃 `CustomBlending (ZeroFactor, OneMinusSrcAlphaFactor)`
  —— 结果 = `dst × (1-alpha)`，只压暗不加亮。用 NormalBlending 会在黑底上加褐雾（实测反而变亮 3%）。
- **差速旋转**（着色器内逐粒子）：`ω = uSpin × r^-0.70`。内圈 om(0.3)=2.32、外圈 om(5.4)=0.31，
  快 7.56 倍。`updateGalaxyMatrix()` 只负责倾斜 + 摆动，**不再叠整体自转**，否则差速被抹平。
- **色带必须 HSL 插值**：白 → 金（h≈0.09 s≈0.88 l≈0.76）→ 奶白 → 冷白 → 浅蓝 → 蓝 → 深靛紫。
  RGB 插值的中点是中性灰，观感立刻"廉价"。
- **金色靠"大粒子 + 低 alpha"**：additive 亮度 = Σ(color×alpha)，高 alpha 会让 R/G/B 一起饱和，
  金色变白。外晕 alpha 只有 0.30~0.50 且随半径降到 40%，才保得住色相。
- **尘埃在旋臂之间**：`arm×72° + r×1.24 + 36° - r×0.22`，抖动 ±0.15 rad，半径从 1.30 世界起。
- **标题保护**：`text-shadow: 0 2px 10px rgba(0,0,0,.9)` + `0 1px 3px rgba(0,0,0,.95)`，
  背后 `.hero::before` 一层径向暗场。实测对比度 49.52:1，字间 p10 亮度 0。
- 世界单位换算：**1 世界单位 ≈ 62.7px**（读 `spaceNav.projection().ndcWidth` 反推，别估）。

## 内核与后处理泛光

- **核球 900 颗，四层**：炽核 80（4.7-8.6px、alpha 0.9-1.0、r<10px，是泛光的燃料）
  / 内核 300（1-2px、铺到 14px）/ 中环 280（1.5-3.4px、14-34px，专门填亮度肩部）
  / 金晕 240（2-4.7px、31-60px，"淡金黄"外圈）。
  削减密度后亮度靠"少数极亮粒子 + 泛光"承担，而不是靠堆数量。
- **四层都用斐波那契球采样**。随机球面必有团块，投影出来是歪的亮球
  （实测边缘半径 12-21px 乱跳）；黄金角螺旋让二阶矩长/短轴比从 1.75 降到 **1.10**。
- **自研 Bloom**（vendor 里没有 EffectComposer，只有 three 主包和两个 addon）：
  ```
  场景 → rtScene(全分辨率) → 亮部提取 → 1/2 → H/V → 1/4 → H/V → 1/8 → H/V → 1/16 → H/V
       → 合成 base + Σ(wᵢ·blurᵢ)，过 g/(1+g) 软肩
  ```
  **10 个 pass**（1 亮部 + 4 级×2 可分离高斯 + 1 合成），全分辨率场景不降采样，锐利度零损失。
- 三个必须记住的实现细节：
  - 第一级模糊的输入不能是它自己的输出纹理（同纹理读写，GL 静默返回黑）。
  - 8 位 RT 存不了 >1 的值，`base + g*strength` 会钳出硬边，必须用 `g/(1+g)` 软肩。
  - 泛光要乘暖偏 `(1.00,0.945,0.855)`，否则白核的辉光会把外圈的金色冲成中性白。
- **参数**：阈值 0.42（旋臂 p90≈0.08，远在阈值下，泛光只由核球驱动）、
  强度 5.0、四级权重 1.05/0.92/0.78/0.60。光球半径 128px，20px 处亮度是关泛光时的 3.4 倍。
- **只在首页启用**：进分类页时 `bloomK` 缓动到 0，整条链路跳过，黑洞页零影响。
- 调参工具：`.checks/bloom-decide.cjs`（阈值×强度 × 核心亮度 vs 旋臂泛白）、
  `.checks/bloom-probe.cjs`（剖面 / 暖色 / 性能）。

### 黑洞：逐像素积分光子轨道

不是贴图，也不是屏幕空间近似。每个像素发一条光线，在「相机 + 光线」张成的平面内求解史瓦西零测地线

```
d²u/dφ² + u = 1.5 · rs · u²        (u = 1/r)
```

速度 Verlet 步进，步长按半径自适应（近洞 0.007 rad / 远处 0.055–0.165 rad），上限 230 步。于是：

- **引力透镜**：射线被弯折，逃逸后用最终方向采样星空 → 环状拉丝与爱因斯坦环。
- **三维吸积盘**：每步还原 3D 坐标并检测与赤道面 `y=0` 的穿越，插值求交点、算交点半径。
  近侧盘因此挡在视界**前面**，远侧盘被挡住，其光被弯到洞的上下方形成那两道弧。
- **多普勒集束**：交点处按 `v=sqrt(GM/r)` 算速度，`D=1/(γ(1-β·n̂))`，亮度 `D^2.5`，色温随 D 偏移。
- **阴影边界用解析判据** `b < 3√3/2·rs`（第一积分 `du²+u²-rs·u³=1/b²` 反解 b）。
  不能靠"积分到掉进视界"：临界光线要绕很多圈，步数一截断就会把阴影半径从 2.60 胀到 3.95。
  但也不能用它提前 return 黑色——盘面近侧就在视界前面。
- **盘有真实的几何厚度**（`DISK_H`，约内缘半径的 5%）：光线穿盘的弦长 `2H/|sin i|` 决定光学深度。
  零厚度的数学平面在掠射角下只剩一条线、视界周围不会有光环；有了厚度，被弯折的像才会铺成一圈细密光弧。
- 相机真的在绕黑洞转：横向拖拽改方位角、纵向改仰角（**-0.20..0.34 rad**，上限刻意收着，
  再抬高就会重新变成“蘑菇”），悬停还有 ±0.045 rad 摆动。
  盘是轴对称的，所以绕轴公转时盘面不变、变的是背景星空——这是物理正确的。
- **比例**：阴影半径 = `(b_crit/CAM_D)/TF`，盘半径 = `(R_OUT/CAM_D)/TF`，
  两者之比只由 `b_crit/R_OUT` 决定。当前 `R_OUT=5.4` → 比 0.48（视界占画幅高 46%）。
  `R_OUT` 一旦超过约 7 就会变成“发光蘑菇”，跟相机远近无关。
- **色温按观测温度取色，不再"基色 × 红移"**：`tempColor(T)` 走一条单调的 Planck 近似色带
  （冷白 → 暖白 → 橙 → 暗红 → 近黑）。乘性偏色会让冷白基色和红移互相抵消、落回中性灰，
  那正是上一版左侧那块"灰白色块"的成因之一。静止温度内缘 7000K、外缘约 2900K。
- **多普勒断崖**：色移 `T·D^3.2`、集束 `min(D^4.0 × 0.72, 3.20)`。指数刻意大于物理值——
  真实 D≈0.78 只够把颜色压到暖黄，这里要的是左侧一路走到深暗红再进黑（实测左右 5.3x）。
  上限定在 3.20 是为了不让任何区域被推到全通道削顶（削顶 = 死白 = 色相消失）。
- **光子环（n≥1 的像）用解析求和**：`b ≈ b_crit` 的光线要绕黑洞大半圈才再穿一次盘面，
  逐圈积分需要上千步。这些像沿 `b` 按 `e^(-nπ)` 几何收敛，闭式求和即可。
  两条硬约束：只对**逃逸**光线生效（否则阴影会被填满）、代表点的半径与多普勒改成
  `b` 与屏幕方位角的**连续函数**（用积分步上的 `pNear` 会成块跳变 → 环上出现马赛克）。
- **高阶像只让积分器留 10%**（`passN<2 ? 1.0 : 0.10`）：第 2 次及以后的盘面穿越在屏幕上
  是绕洞一圈才落回来的像，采样步长在这个尺度上不够细，全额累加叠上集束就是一块削顶的白板。
  n≥1 的像由解析环项负责，积分器再算一遍属于重复计数。
- **环的厚度**来自两层：密度加底（`mix(0.72, dens, 0.42)`，n≥1 像是多圈叠加、湍流已被抹平）
  + 轨道离盘面的距离调制（`mix(0.30, 1.0, exp(-(y/H)²))`），于是横带亮、上下弧薄。
  另加一层"暗红余烬"下限，保证多普勒把背向侧压到极暗时环仍几何闭合。
- **掠射弦长用软分母** `2H/sqrt(vy²+9e-4)`：原来的 `min(2H/max(|vy|,0.010),9.0)` 有两个硬折点，
  `|vy|` 跨过阈值的那一列像素弦长会跳两个数量级，色块边界就是锯齿。
- **鼠标引力透镜**：`main()` 取光线方向之前先把采样坐标按点透镜公式掰弯，
  吸积盘、光子环、星空一起被拖动。位移夹在 `0.34·θ` 以内——纯 `β = θ - θE²/θ` 在 `θ<θE` 时
  会把采样点翻到光标对面，星星被打成乱码而不是"被拉扯"。作用半径 0.58（约 0.29 屏高），
  另加 0.34 的切向卷曲让星星被拉成弧；指针进出有缓动；拖拽时强度降到 0.35。
- 背景**没有任何雾**：`sky()` 里那层 `vec3(0.020,0.030,0.055)` 的"星际尘埃"是灰绿脏雾的唯一来源，已删除。
- 自转 `om=0.30·r^-1.5`（内缘一圈约 78 秒），湍流时间系数也压到极小——气流是“缓缓流动”而不是闪。
  实测 40ms 间隔的帧间抖动 mean 1.6、跳变超过 40 的像素 0%。
- 只在分类页渲染：`bhFrame()` 在首页 / 手机端（视口隐藏）直接返回且不再调度。
- 分辨率自适应由**丢帧数**驱动（帧间隔被 vsync 压平，看均值只会一路降档）：90 帧窗口内
  `dt>25ms` 超 7 次降档，连续 6 个窗口零丢帧才升一档。默认内部倍率 0.82，收敛后仍 60fps。
- 场景里**没有引入 EffectComposer**：整页只有 `import * as THREE from 'three'`，
  vendor 里的 addons 文件虽在盘上（为将来保留），但**不被任何模块 import，浏览器不会下载**。
  鼠标引力的 UV 位移直接写在光子追踪 shader 的最前面，效果等价于一个 ShaderPass，
  但少一次全屏 RT 与一次 draw call。要换成真 EffectComposer，把那段位移搬进 `ShaderPass` 即可。
- 场景里**没有任何后处理**（无 EffectComposer / UnrealBloom）。之前“高光糊成一团”是光学深度饱和
  （`tau` 上限过高导致 α→1 硬边）加上亮度系数过大，不是 bloom。

## 粒子与绘制

分层自下而上，亮度严格递增：

1. **深空底色**：3D 场景最底层一张渐变平面（距离 860，中性近黑 `#050508`），不透明铺满。实测角落亮度 9–14.5。
2. **暗星云**：fragment shader 的 domain-warped fbm 噪声程序化生成，**一次性烘焙到 2048×1280 离屏纹理**（0.4–0.6 s），之后每帧只做一次贴图采样。不透明度 **0.15–0.20**，径向 falloff 只覆盖中心偏右下一带；配色是灰紫微光 → 暗玫瑰 → 暗酒红 → 暗紫 → 暗蓝 → 近黑。实测亮区均值 33（p99 76），左侧 5.6。
3. **星尘**：7000 微星（直径 1–3px）+ 50 主星（直径 5–14px、alpha 0.30–0.50），带逐粒子视差。**十字星芒已整体关闭**（`aSpike` 全为 0，shader 分支保留）。
4. **主星系**：5000 点，五条旋臂 + 球形核球，加色混合。实测 p99 178、核心 255 —— 画面唯一的高光所在。
5. **前景 UI**：白色标题 + Dock（`rgba(0,0,0,.62)` + `blur(18px)`）。

粒子层合并在**同一个** `THREE.Points`，共享一个 BufferGeometry 和一个 shader material；全场 **12050** 点、1 个 draw call。用 `aLayer` 区分「星系（倾斜+进动+自转矩阵）」与「星场（按 `aPar` 做视差）」。整场 **4 次 draw call**（粒子 + 2 星云 + 深空底）。

其他约束：

- 星云按「天穹」定位：每帧贴住相机视轴并复制相机朝向，缩放不推动星云，只有视差会让它动。
- **色彩空间必须正确**：星云烘焙纹理与深空底色贴图都要标 `SRGBColorSpace`。标成 `NoColorSpace` 会让中间调整体抬亮（0.2→0.48），表现为「暗部发灰、饱和区发艳」。
- 星点尺寸按投影反推：`gl_PointSize ≈ aSize*1158/dist`，`aSize` 太小会变成亚像素点、整层等于没画。
- 自转 0.0011 rad/s（盘沿约 0.39 px/s，盯十秒才察觉），进动周期约 108 秒；滚轮缩放带阻尼，`camera.position.z` 严格夹在 [10, 40]。
- 相机远裁剪面 2600 —— 必须大于深空底色距离（860），否则最底层会被裁掉。
- 所有粒子使用 vertex colors、单个自定义 shader 绘制解析圆点，不使用外链图片、GLB、阴影或后期处理。
- 分类切换只重排星系层的 position / color typed arrays（星场仅整体压暗），并插值相机距离。
- 考虑系统减少动态效果设置；无动画时停止循环帧更新，交互过渡仍能执行。
